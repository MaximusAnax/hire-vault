Executive Summary

Phase 2 delivers multi-source profile ingestion: resume upload with GPT-4o parsing, LinkedIn JSON import (MVP), hash-based deduplication with conflict resolution UI, and profile validation/enrichment suggestions.

  • @hirevault/ai-core: Zod schemas, SHA-256 hashes, OpenAI parse/validate
  • Storage: Private resumes bucket + ingestion_runs audit table
  • Dedup: DB triggers for source_hash + dedup_conflicts queue
  • UI: /profile/import — upload, LinkedIn paste, conflicts, quality score
  • Profile: Inline experience edit via ExperienceRow
