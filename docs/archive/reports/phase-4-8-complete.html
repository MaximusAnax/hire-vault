Known Weaknesses
  • Job scrapers will break on site redesigns — use manual paste.
  • ATS score is keyword heuristic, not vendor-specific simulation.
  • PDF export uses browser print, not programmatic PDF generation.
  • Mock interviews are text-only (no voice).
  • Company research returns static stub until external API key is added.
  • Migration 20260521180000 must be applied manually in Supabase.
Break-This Challenges
