# M2 — Frictionless job capture + save

## Goal

Save a real job in under ~10 seconds from the app or Chrome extension.

## Builder deliverables

- Harden `scrape.ts` (LinkedIn blocked hint, location dedupe on save).
- Smart capture: Enter to parse, preview → single save (no re-parse on save).
- Extension: MV3 build, scrapers, `POST /api/extension/capture` with `locations[]`.
- `apps/extension` fixture-style unit tests or documented manual E2E checklist in verdict evidence.

## Acceptance rubric (Tester)

| id | check |
|----|-------|
| m2-gates | quality:check pass |
| m2-scrape-tests | scrape.test.ts green; LinkedIn returns blocked + hint |
| m2-preview-save | JobPreviewCard saves without second AI parse |
| m2-locations-dedupe | duplicate location chips collapsed server-side |
| m2-extension-build | `pnpm --filter @hirevault/extension build` succeeds |
| m2-capture-api | extension route accepts title + description + locations |
