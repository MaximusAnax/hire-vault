# M1 — Profile fidelity

## Goal

Profile is the source of truth: import/parse accuracy, dedup correctness, hybrid summary engine, edit-everywhere, no data loss on edge-case inputs.

## Builder deliverables

- Vitest for `apps/web/lib/ingestion/dedup.ts` (merge, conflict, hash stability).
- Confirm row components wired on profile page for education, projects, skills, courses.
- Summary snippet cache + manual regenerate; `summary_stale` indicator.
- Import-time bullet polish only (not manual saves).

| id | check |
|----|-------|
| m1-gates | typecheck, lint, test, build all pass |
