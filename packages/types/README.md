# @hirevault/types

Shared TypeScript types mirroring the Supabase schema and app domain models.

## Contents

- Profile entities (`Experience`, `Education`, `Leadership`, …)
- Pipeline types (`ApplicationWithJob`, `ApplicationStatus`, …)
- Job metadata (`JobType`, `RoleSeason`, …)

Import from `@hirevault/types` in apps and packages.

Schema changes: update types here after adding a migration in `packages/supabase/migrations/`.

See [docs/NAVIGATION.md](../../docs/NAVIGATION.md).
